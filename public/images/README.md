# Images

Drop your real underwater photos here with these exact filenames and they'll
appear automatically on the landing page. Until a file exists, the page shows a
styled placeholder that tells you what photo belongs in that slot.

| Filename        | Where it shows        | Suggested subject                                   | Ideal size (px) |
| --------------- | --------------------- | --------------------------------------------------- | --------------- |
| `hero.jpg`      | Full-screen hero      | Wide, sunlit scene — reef, blue water, diver         | 2400 × 1400     |
| `about.jpg`     | About section         | A portrait of you, ideally underwater / dive-related | 1200 × 1500     |
| `feature.jpg`   | Featured strip        | The dive or project you most want to highlight       | 1600 × 1200     |
| `gallery-1.jpg` | Photo gallery         | A favourite underwater shot                           | 1200 × 1200     |
| `gallery-2.jpg` | Photo gallery         | A favourite underwater shot                           | 1200 × 1200     |

## Tips

- **Use your own dive photos** for a personal, authentic feel.
- Free, license-clear underwater photography: [Unsplash](https://unsplash.com/s/photos/underwater),
  [Pexels](https://www.pexels.com/search/underwater/). Download and save with the
  filenames above.
- Keep files reasonably sized (compress to < ~400 KB each) so the page stays fast
  on GitHub Pages. Tools: [Squoosh](https://squoosh.app), or `sips`/`ImageOptim` on macOS.
- `.jpg` is assumed. If you prefer another extension, update the `src` paths in
  `src/pages/index.astro`.
